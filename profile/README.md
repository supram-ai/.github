# Supram

Open, dependable workflows for AI-assisted software engineering.

Supram is a family of tools that make AI coding assistants accountable: structured phases,
human gates, independent review, evidence, and durable project continuity.

## Public projects

- **[supram-oss](https://github.com/supram-ai/supram-oss)** — the free, file-based engineering
  protocol: conventions, templates, command contracts, and personas. Start with the
  [quickstart](https://github.com/supram-ai/supram-oss#quickstart).

## Commercial

The licensed product family (Supram CLI, Supram Gateway, Supram Server) builds on the same
protocol with deterministic enforcement, project memory, multi-repo coordination, and hosted
services. Learn more at [supram.ai](https://supram.ai).
